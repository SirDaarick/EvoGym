# Shift Close Modal with Durable Autosave

## Objective
Replace the inline shift-close panel with an accessible, responsive EGC modal that autosaves count inputs and observations and can recover them after reload or browser close in the same browser.

## Problem and rationale
Close inputs currently live only in the Shifts component. The demo's operational state also lives only in memory, so saving the draft alone would restore it against reseeded financial records. Persist the operational dataset and drafts together while keeping shift-review authorization ephemeral.

## Scope and constraints
- Use native `<dialog>`, existing denomination validation and expected-cash formula, EGC tokens, and current close permissions/revision guard.
- Persist the operational `DemoState` and shift-keyed drafts as one versioned browser-local record. Do not persist staff profile/PIN data or cross-device sync.
- Draft writes never change financial `revision`; every resumed count requires a fresh review.
- Close the current shift with an optional note; do not add a recipient, cash-transfer movement, or open the next shift automatically.
- Preserve all pre-existing dirty changes; do not stage unrelated work.
- Current worktree is on `codex/component-catalog-extension` with 104 pre-existing modified/untracked paths; several relevant feature files already contain uncommitted content. Any commit must isolate this feature's exact changes and must not absorb unrelated changes.

## Acceptance criteria
- A count and its operational financial dataset resume together after a reload/browser restart in the same browser.
- Drafts are isolated by dataset identity and shift; reset clears old drafts.
- Invalid partial raw inputs autosave but cannot pass review.
- Editing/autosave does not stale a review; real financial revision changes do. Review confirmation cannot be resumed after reload.
- Only one same-origin tab can write; blocked secondary tabs explain how to retry.
- Failed persistence never claims saved or confirms delivery; the draft remains available to retry.
- Successful delivery stores counted cash, expected snapshot, difference, notes, and removes only that shift's draft atomically.
- Desktop, tablet, mobile, light/dark, keyboard focus, Escape, and reduced-motion behavior meet the approved design.
