# React Bits catalog sources

These nine TS-CSS components were copied from the free `@react-bits/<Name>-TS-CSS` registry entries at `https://reactbits.dev/r/` on 2026-10-10. The registry source, rather than a visual reimplementation, is kept beside each stylesheet. The complete upstream MIT + Commons Clause notice is in `LICENSE.react-bits.md`.

The local integration confines usage to the `/components` catalog. `MagicBento` accepts catalog-owned card data instead of relying on its generic defaults, and its stylesheet root tokens are scoped to `.react-bits-gallery`. The gallery supplies EvoGym color tokens, fictional data, and reduced-motion settings. Future registry refreshes should preserve these adaptations and recheck dependency and license terms.

Registry entries: `CodeSlots`, `JellyRadio`, `RubberSegment`, `SpringCheck`, `SquishSwitch`, `SwipeToast`, `MagicBento`, `AnimatedList`, and `Stepper`, each with the `-TS-CSS` variant.
